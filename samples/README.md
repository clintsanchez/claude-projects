# Samples

Reference outputs from running the marketing templates end-to-end. Useful as:
- Format reference (what a "shipped" deliverable looks like)
- QA — comparing future runs against a known-good baseline
- Examples to share with team members or clients

These are not part of the production pipeline. The active outputs you ship live in `output/` (gitignored).

## Files

- `posts/[slug].docx` — one finished post per file. Hooks, body, visual placeholder + spec, production notes. Open in Word, Pages, or Google Docs.
